# Issues

**Dojo Count Inconsistency**
- **Description**: In the Maths challenge section, the right panel shows 5 dojos created, while the left panel displays a count of only 4 dojos. The count is not synchronized between panels.
- **Priority**: High
- **Severity**: Major
- **Steps to reproduce**:
Navigate to Dojos section
Select "maths" challenge from left panel
Observe total dojo count on left panel
Compare with number of dojos displayed on right panel
Notice mismatch in count


**Filter Functionality Issue (Active Status)**
- **Description**: When the "Active" filter is applied, both active and inactive dojos are displayed instead of only active ones.
- **Priority**: High
- **Severity**: Critical
- **Steps to reproduce**:
Navigate to Dojos section
Select any challenge (e.g., computer class)
Apply "Active" filter from status dropdown
Observe the dojo list
Notice inactive dojos are also displayed



**Incorrect Inactive Dojo Count**
- **Description**: The count of inactive dojos in the Maths challenge does not match the actual number of inactive dojos displayed.
- **Priority**: Medium
- **Severity**: Major
- **Steps to reproduce**:
Navigate to Dojos section
Select "maths" challenge
Apply "Inactive" filter
Observe displayed dojos and count
Compare count with actual number of inactive dojos shown
Notice mismatch




**Google Account Linking Button Not Working**
- **Description**: Clicking the "Link with Google" button in the Social Accounts section does not trigger any action, redirect, or account linking process.
- **Priority**: High
- **Severity**: Major
- **Steps to reproduce**:
Login to the application
Navigate to Profile page
Open the "Account Information" tab
Locate the "Link with Google" button under Social Accounts
Click on the button
Observe the behavior
Expected Result: User should be redirected to Google authentication/account linking flow.
Actual Result: No action occurs when clicking the button
